# Fitness Tracker

Log workouts and track progress toward daily goals.

## Features

* Log exercise type, workout minutes, calories and steps
* Dashboard with daily progress bars and a 7-day bar chart
* Data stored in a SQLite database (fitness.db)
* Delete entries, input checking

## Requirements

* Python 3.8+ (everything used is built into Python, **no pip installs needed**)
* On some Linux systems: `sudo apt install python3-tk`

## How to run

Open a terminal then:

```bash
python fitness\_tracker.py
```
