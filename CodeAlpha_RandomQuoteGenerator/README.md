# Random Quote Generator

Shows an inspiring quote and its author.

## Features
- A random quote when the app opens
- New Quote button (never the same quote twice in a row)
- Copy button

## Requirements
- Python 3.8+ (everything used is built into Python, **no pip installs needed**)
- On some Linux systems: `sudo apt install python3-tk`

## How to run
Open a terminal **inside this folder**, then:
```bash
python quote_generator.py
```
