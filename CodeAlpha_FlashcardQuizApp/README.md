# Flashcard Quiz App

A desktop study app with question and answer flashcards.

## Features
- Question on the front, answer on the back (Show Answer button)
- Next / Previous buttons (also arrow keys, Space to flip)
- Add, edit and delete flashcards
- Cards saved automatically in flashcards.json

## Requirements
- Python 3.8+ (everything used is built into Python, **no pip installs needed**)
- On some Linux systems: `sudo apt install python3-tk`

## How to run
Open a terminal **inside this folder**, then:
```bash
python flashcard_app.py
```
