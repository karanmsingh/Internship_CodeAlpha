CodeAlpha Python Projects
Projects built during my Python Programming Internship at CodeAlpha (October 2026).
Each project lives in its own folder with its own README and instructions.
Projects
Project	Description	Tech
Flashcard Quiz App	Study with flashcards: show answers, move between cards, and add, edit or delete them.	Python, Tkinter, JSON
Random Quote Generator	Shows a random inspirational quote and author, never repeating the same quote twice in a row.	Python, Tkinter
Fitness Tracker	Log workouts, calories and steps, with daily progress bars and a 7-day chart.	Python, Tkinter, SQLite
Language Learning App	Learn Spanish, French and German with flashcards, pronunciation guides, quizzes and progress tracking.	Python, Tkinter
Requirements
Python 3.8 or newer
No extra packages needed (Tkinter and SQLite come with Python)
On some Linux systems: `sudo apt install python3-tk`
How to run a project
Download or clone this repository.
Open a terminal inside the project's folder, for example:
```bash
   cd CodeAlpha_FitnessTracker
   python fitness_tracker.py
   ```
