# Language Learning App

Learn Spanish, French and German with flashcards and quizzes.

## Features
- Categories: Daily Lesson, Vocabulary, Phrases, Grammar
- Flashcards with translation and pronunciation
- 10-question multiple-choice quiz
- Progress tab (scores saved in progress.txt)

## Requirements
- Python 3.8+ (everything used is built into Python, **no pip installs needed**)
- On some Linux systems: `sudo apt install python3-tk`

## How to run
Open a terminal **inside this folder**, then:
```bash
python language_app.py
```
